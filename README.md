# Clutch Gang Movie

Official one-page website for the documentary *Clutch Gang*.

The site is intentionally built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a paid website builder or ongoing software subscription.

## Updating the site

- Page copy and links: `index.html`
- Colors and visual styling: `styles.css`
- Poster and font: `assets/`

## Domain

The production domain is `clutchgangmovie.com`.
